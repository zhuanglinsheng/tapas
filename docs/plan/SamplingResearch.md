# Tapas 概率采样研究：分布保持的冲突泛化与 Rule Item 校准

## 结论

这条研究路线有发表潜力，但需要把贡献收紧到一个现有工作没有直接回答的问题：

> 给定业务输入的先验分布和一组可求解的业务规则，如何在**完全保持可行输入的条件分布**的同时，利用有限的额外求解预算，从失败查询中学习能够覆盖尽可能多先验概率质量的不可行区域，从而减少后续求解器调用？

单独提出“采样时缓存 UNSAT core”不够新。SampleSearch 已经把概率采样、约束搜索、回溯和 no-good learning 组合起来；广义 no-good、MUS 提取、preferred MUS、加权模型采样和覆盖导向的随机测试也都有成熟研究。Tapas 可以形成清晰区别的地方有三点：

1. **分布保持的概率质量 core 泛化**：学习只位于不可行域中的区域，以“未来可省去的求解器调用”而不是 core 大小作为目标，明确分布保持的理由，并给出摊销收益条件。
2. **基于 Rule Item 的分布校准**：把业务规则中的命名条件直接作为测试分层，在每个分层内部保留业务先验分布，同时控制各类成功和拒绝情形的测试比例。
3. **成对反事实测试**：围绕同一个业务场景生成仅在目标 Rule Item 上改变结论的成功／失败对。这更适合作为前两项能力的应用和展示，不宜单独作为主要理论创新。

如果第一项只有启发式算法和少量示例，论文会很容易被评价为“已有 SampleSearch/no-good learning 的工程组合”。如果能完成正式目标、正确性证明、预算化算法、严格基线以及跨分布和约束结构的实验，它可以成为主贡献；第二项可以把算法与 Tapas 的规则抽象连接起来，形成完整的测试系统论文。

## 现有工作把创新空间压缩到了哪里

### 采样与约束搜索

SampleSearch 直接研究了带大量零概率或硬约束的概率模型。它在采样遇到死路时继续执行系统搜索，生成一定可行的样本，并刻画由搜索产生的 backtrack-free distribution；由于搜索会改变分布，论文还需要重要性权重来消除或渐近消除偏差。该工作明确讨论了约束传播、回溯、no-good/clause learning 和缓存。因此，“用求解器补全部分采样，并从失败中学习 no-good”本身已有明确先例。

Tapas 的算法应当强调另一条语义：每次仍从用户给定的先验分布独立提出业务输入，求解器只回答这些输入是否存在可行补全；学习到的不可行区域只用于跳过本来必然被拒绝的查询。因此，输出无需重新加权，仍然精确服从原先验在可行域上的条件分布。这一选择不会自动解决极低可行率造成的大量随机提案，却能显著减少其中昂贵的求解调用。

加权和投影模型采样也已经很成熟。WeightGen 一类工作研究按赋值权重近似采样满足解；projected model counting 和 weighted projected sampling 研究只关心一部分投影变量、其余变量只需存在扩展的情形。这与 Tapas 的“先采样业务输入，再由求解器补全其他变量”在数学结构上高度相似。论文不能把投影或加权采样本身作为新意。

### UNSAT core、MUS 与 no-good

求解器返回的原始 UNSAT core 一般只保证不满足，不保证最小。MUS 是按集合包含关系最小的不可满足子集；minimum core 通常指基数最小的 core，两者不能混用。MUS 提取和枚举已有大量算法，完整枚举可能产生不可处理数量的 MUS。preferred MUS 也已有研究，并分析了偏好顺序下求解的复杂度。

这意味着“寻找更小的 core”不是合适的新目标。概率质量目标与传统目标有实质区别：

- 最小基数只计算保留了几个假设；
- preferred MUS 通常依据给定的词典序或偏序；
- Tapas 关心该 core 所代表的整个不可行区域在业务先验下有多大概率，以及为找到它额外花了多少求解调用；
- 当先验有关联时，区域质量不是各变量权重的简单相加，已有的加权 MaxSAT core 也不能直接代表这个目标。加权 MaxSAT 中的权重通常是违反软约束的代价，不是被排除输入区域的联合概率。

不过，概率质量 core 仍属于 preferred explanation / generalized no-good 的邻近问题。论文必须把新目标、算法和实验写得足够具体，不能只换一个评分函数。

### 测试分布和覆盖校准

硬件验证长期使用 constrained-random testing 和 coverage-directed generation；软件测试也有 operational-profile testing、覆盖导向的测试选择和学习式分布调整。Luck 允许在逻辑谓词上附加分布及求解控制，并证明生成器相对于谓词语义的可靠性；predicate-complete coverage 关注可达谓词真值组合。由此可见，“按规则条件覆盖测试”也不能单独成为主要创新。

Rule Item 校准仍有系统价值，因为 Tapas 可以给出一个自然且可执行的业务抽象：同一个 Item 同时用于定义业务规则、构造精准违反、标记测试分层和解释求解结果。比较稳妥的学术定位是“语义接口与校准方法”，而不是声称发明了覆盖导向采样。

### 成对反事实

最小改变的通过／失败测试对与 causal testing、反事实解释、变形测试有明显重叠。Causal Testing 已经通过对失败测试进行最小变化，生成通过和失败的成对执行来帮助定位根因。因此，Tapas 的成对反事实更适合作为业务规则场景中的产品特色：它可以证明 Rule Item 变换很有用，也能展示采样和求解如何协同，但除非提出新的耦合分布或新的最优性结果，不宜作为独立主贡献。

## 正式问题

让求解器返回任意满足 Rule 的赋值不能构成概率测试生成，因为求解器的搜索顺序不代表业务输入的真实频率。先随机生成全部变量再拒绝非法样本也不理想：用户需要为预期结果和操作后状态一并设计分布，而且严格规则会造成大量无效求解。

本文研究的问题是：给定业务输入的先验分布和一组可求解的业务规则，如何按照先验在可行输入上的条件分布生成测试，并由求解器补全其余变量；同时，如何复用失败查询产生的 UNSAT core，减少后续求解器调用而不改变该条件分布。

这个问题包含两个相互约束的目标。统计上，输出必须保留可行业务输入在先验中的相对概率；计算上，算法应尽量避免对已经能够证明不可行的输入区域重复求解。前者定义采样语义，后者决定 core 学习可以进行哪些优化。

## 模型设定

整体采样流程如下：

1. 按照用户给出的业务分布生成一组候选输入；
2. 固定这些已知输入，调用求解器补全其余变量；
3. 求解结果为 SAT 时输出完整测试，结果为 UNSAT 时拒绝候选输入，结果为 UNKNOWN 时返回诊断且不学习任何不可行结论；
4. 重复以上过程，直到得到所需数量的测试或达到运行预算。

缓存只包含经过 UNSAT 证明的不可行区域，因此提前拒绝缓存命中的输入只是省去一次必然失败的求解，不会排除任何可行输入，也不会改变最终输出在可行域上的条件分布。

core 学习处理第三步产生的 UNSAT 结果。它的目的不是改变采样规则，而是记住已经证明不可行的输入区域：后续候选输入若落入这些区域，便可以直接拒绝，不再重复调用求解器。

每次查询时，候选输入中的各个已知取值都作为可追踪的绑定交给求解器。若全部绑定共同导致 UNSAT，求解器可以返回其中一组已经足以造成冲突的绑定，这组绑定称为 UNSAT core。例如，一次查询固定了五个变量，但冲突只依赖“会员等级为普通”和“折扣率为 80%”，那么另外三个取值都与不可行性无关。任何同时满足这两条绑定的输入都不可能被补全为合法测试，因此这个 core 表示的是一片不可行区域，而不只是最初失败的一个输入点。

求解器返回的原始 core 通常仍包含多余绑定。算法可以尝试逐条移除绑定，并重新检查剩余绑定是否仍然导致 UNSAT。每移除一条绑定，core 所描述的区域都会扩大；只有求解器再次证明整个扩大后的区域不可行，算法才接受这次泛化。因此，无论提炼在何时停止，已经得到的区域都是安全的。

本文与通常方法的主要区别在于如何评价这些泛化结果。直接保存完整失败输入或原始 core，成本较低，但往往只能覆盖很小的区域；包含关系最小的不可满足核（MUS）和最小基数 core 则分别追求无法继续删除绑定和绑定数量最少，却没有考虑业务输入实际出现的概率。在偏斜或相关分布中，绑定更少并不一定意味着更容易再次命中；如果新区域与缓存大量重叠，它的实际收益也会很小。

因此，本文不以 core 的大小为最终目标，而以候选区域在现有缓存之外新增覆盖的先验概率质量来衡量价值，并同时考虑预计还会产生多少候选输入以及泛化需要增加多少求解调用。这个目标直接估计一项泛化在后续采样中能够省去多少次求解。选中的 core 随后进入缓存；新候选输入只有在未命中任何缓存区域时才提交给求解器。

### 变量与约束

第一版只讨论有限离散域，与 Tapas 当前支持的 Bool、Enum、有限点集和带配置边界的 Int 一致。

把由用户分布直接采样的变量记为 $X=(X_1,\ldots,X_d)$，联合取值空间为 $\mathcal X$，具体取值记为 $x\in\mathcal X$。把由求解器补全的变量记为 $Y=(Y_1,\ldots,Y_e)$，联合取值空间为 $\mathcal Y$，具体取值记为 $y\in\mathcal Y$。

Rule 编译得到的约束记为 $R(x,y)$；$R(x,y)$ 为真表示完整赋值 $(x,y)$ 满足全部规则条件。$X$ 决定测试输入的概率语义，$Y$ 负责把部分输入补全为完整测试；这里不假定 $Y$ 具有用户指定的概率分布。

### 业务先验

用户为 $X$ 提供联合先验概率质量函数 $\pi$：

$$
\pi(x)=\Pr[X=x],
\qquad
\sum_{x\in\mathcal X}\pi(x)=1.
$$

$\pi$ 描述应用 Rule 之前业务输入的自然发生频率，可以是独立变量分布的乘积，也可以直接表达变量之间的相关性。下文用 $\Pr_\pi[\cdot]$ 表示 $X\sim\pi$ 时事件的概率，并用

$$
\pi(G):=\Pr_\pi[X\in G]
$$

表示输入区域 $G\subseteq\mathcal X$ 的先验概率质量。

### 可行输入

可行输入集合、不可行输入集合和可行概率分别定义为：

$$
\begin{aligned}
F &= \{x\in\mathcal X\mid \exists y\in\mathcal Y:R(x,y)\},\\
F^c &= \mathcal X\setminus F,\\
Z &= \pi(F)=\Pr_\pi[X\in F].
\end{aligned}
$$

$F$ 是完整解空间在采样变量 $X$ 上的投影。$x\in F$ 表示它至少存在一种合法补全；$x\in F^c$ 表示任何 $y$ 都不能使 Rule 成立。后文假定 $Z>0$，否则当前先验的支持集内不存在可生成的测试。$Z$ 越小，普通 rejection 获得可行输入的成本越高。

### 目标分布

用 $\mathbf 1[P]$ 表示命题 $P$ 的指示函数。目标概率质量函数是先验 $\pi$ 在 $F$ 上的条件分布：

$$
\mu(x)
:=\Pr_\pi[X=x\mid X\in F]
=\frac{\pi(x)\mathbf 1[x\in F]}{Z}.
$$

对于任意具有正先验质量的 $x,x'\in F$，有

$$
\frac{\mu(x)}{\mu(x')}
=\frac{\pi(x)}{\pi(x')}.
$$

因此，条件化只移除不可行输入，不改变其余输入的相对概率。$\mu$ 只有在 $\pi$ 均匀时才是 $F$ 上的均匀分布；求解器任意返回的满足赋值一般不具备这一性质。

### 输出语义

对于每个 $x\in F$，定义 witness 集合

$$
W(x)=\{y\in\mathcal Y\mid R(x,y)\}.
$$

若 `solve::sample` 产生 $n$ 个输出 $(X^{(j)},Y^{(j)})$，第一版应承诺

$$
X^{(1)},\ldots,X^{(n)}
\overset{\mathrm{iid}}{\sim}\mu,
\qquad
Y^{(j)}\in W(X^{(j)}),
\quad j=1,\ldots,n.
$$

这里 $\overset{\mathrm{iid}}{\sim}$ 表示各输入独立同分布。概率采样允许重复输入。概率保证只适用于 $X$；当 $W(x)$ 包含多个值时，求解器给出的 $Y^{(j)}$ 只是存在性见证。若需要控制 $Y$ 的概率，必须把相关变量纳入 $X$，或者另外定义 witness 的条件分布。

### 适用边界

以上模型要求先验 $\pi$ 可被采样，Rule 的有限域语义与求解器模型一致，并且只有可靠的 SAT 和 UNSAT 结论用于接受样本或学习不可行区域。UNKNOWN、超时和不受支持的表达式不能被当作 UNSAT。

## 不可行区域和概率质量 core

一次完整失败输入 $x$ 可以写成假设集合：

$$
A_x=\{X_1=x_1,\ldots,X_d=x_d\}.
$$

当 $A$ 是一组假设时，$R\land A$ 表示 $R$ 与 $A$ 中所有假设的合取。若求解器证明 $R\land A_x$ 不可满足，并返回 $C\subseteq A_x$，且

$$
R\land C\text{ is UNSAT},
$$

则称 $C$ 为这次失败查询的一个 UNSAT core。它表示不可行柱状区域：

$$
G(C)=\{x'\mid x'\models C\}.
$$

这里 $x'\models C$ 表示 $x'$ 满足 $C$ 中的全部等值假设。所有未出现在 $C$ 中的输入变量都可以自由变化。由 UNSAT 可知 $G(C)\cap F=\varnothing$。普通 full no-good 对应完整假设集 $A_x$，其禁止区域 $G(A_x)=\{x\}$ 只包含一个完整赋值；core no-good 禁止整个 $G(C)$，可以一次排除大量完整赋值。

本文后续所说的 MUS 都是相对于固定硬约束 $R$ 而言：core $C$ 满足 $R\land C$ 不可满足，并且对每个真子集 $C'\subset C$，$R\land C'$ 都可满足。它表示按集合包含关系已经无法继续删除假设，并不保证 $C$ 在所有 core 中具有最小基数。

设 $U\subseteq F^c$ 是当前已经缓存的所有不可行区域的并集。对于一个候选区域 $G\subseteq\mathcal X$，需要区分它的总概率质量和它能为当前缓存增加的概率质量。

总概率质量

$$
\pi(G)=\Pr_\pi[X\in G]
$$

回答的是“一个随机候选输入落入 $G$ 的概率有多大”。但 $G$ 中可能有一部分已经包含在 $U$ 中。落入这部分的输入原本就会被缓存拒绝，再用新 core 覆盖一次并不能进一步减少求解器调用。把 $G$ 按是否已被缓存覆盖分开，可以写成

$$
\pi(G)
=\Pr_\pi[X\in G\cap U]
+\Pr_\pi[X\in G\setminus U].
$$

第一项是与已有缓存重复的质量，第二项才是新 core 真正增加的覆盖。因而定义新增覆盖概率质量

$$
\Delta_\pi(G\mid U)
:=\Pr_\pi[X\in G\setminus U]
=\pi(U\cup G)-\pi(U).
$$

最后一个等式给出了更直观的理解：加入 $G$ 之前，缓存覆盖的质量是 $\pi(U)$；加入之后是 $\pi(U\cup G)$；两者之差就是 $G$ 带来的实际增量。

例如，候选区域 $G_1$ 的总质量为 $10\%$，但其中 $9\%$ 已经包含在缓存中，那么它只能新增 $1\%$。另一个区域 $G_2$ 的总质量只有 $6\%$，却与缓存完全不重叠，因此能新增 $6\%$。如果后续还会产生 $1000$ 个候选输入，缓存 $G_1$ 预计只能额外避免约 $10$ 次求解，而缓存 $G_2$ 可以额外避免约 $60$ 次。按照总质量会选择 $G_1$，按照新增覆盖质量则会选择实际收益更大的 $G_2$。

对候选 core $C$，将上述定义应用到它表示的区域 $G(C)$：

$$
\Delta_\pi(C\mid U)
:=\Delta_\pi(G(C)\mid U)
=\Pr_\pi[X\in G(C)\setminus U].
$$

当缓存为空，即 $U=\varnothing$ 时，新增覆盖质量与总质量相同。随着缓存逐渐积累，core 之间开始重叠，两者才产生差异。因此，单次孤立地评价 core 可以使用总质量；连续学习多个 core 时，新增覆盖质量才对应这个 core 未来能够额外带来的缓存命中。

### 无成本目标

若不计算提炼成本，可定义质量最优 core：

$$
C^*\in\operatorname*{arg\,max}_{C\subseteq A_x}
\Delta_\pi(C\mid U)
\quad\text{s.t.}\quad R\land C\text{ is UNSAT}.
$$

这里 $\operatorname*{arg\,max}$ 返回使目标达到最大值的候选集合，$C^*$ 表示其中任意一个最优 core。

因为删除假设不会缩小区域，所以总能把质量最优 core 继续删成一个质量不低于它的 MUS；如果每次扩张相对 $U$ 都增加正概率质量，非最小 core 会被严格改进。但质量最优 MUS 不一定是基数最小的 MUS。两个同样包含两个假设的 core 也可能因为变量概率不同而相差几个数量级。

令 $\pi_i(x_i)=\Pr[X_i=x_i]$ 表示第 $i$ 个变量的边缘概率质量。当先验中的各个 $X_i$ 相互独立且 $U=\varnothing$ 时，

$$
\pi(G(C))=\prod_{(X_i=x_i)\in C}\pi_i(x_i),
$$

因为 $x$ 是从 $\pi$ 实际抽到的输入，所以公式涉及的 $\pi_i(x_i)$ 都大于 $0$，其对数有定义。此时最大化总质量等价于在 UNSAT 子集上最小化

$$
\sum_{(X_i=x_i)\in C}-\log\pi_i(x_i).
$$

因此，**独立分布下单次 core 的总质量优化可以被视为一个加权 core／preferred MUS 问题，不能单独声称为全新的优化问题**。相关先验必须计算或估计联合边缘概率；而相对缓存并集的边际质量还取决于 core 之间的重叠，不能化成每个文字的固定可加权重。这也是在线目标比“给每个假设加概率权重”更有研究价值的原因。

### 何时值得继续泛化 core

上一节的无成本目标假定寻找更好 core 不需要付出代价。实际情况并非如此：每次尝试移除一条绑定，都可能需要再次调用求解器，以确认扩大后的区域仍然不可行。泛化得越充分，未来可能省去的求解越多；但如果采样很快就会结束，这些节省可能不足以补偿当前的提炼成本。因此，算法需要判断：现在多花几次求解，能否在后续采样中省回更多次求解？

#### 以求解器调用次数衡量

先约定“候选输入”的含义：每当算法从业务先验 $\pi$ 中抽取一个输入、准备检查它能否补全时，就产生了一个候选输入。候选输入可能被接受为测试，也可能因为不可行而被拒绝。令：

- $H$ 表示从当前时刻到采样结束，预计还会产生多少个候选输入；
- $\Delta_\pi(C\mid U)$ 表示一个新候选输入落入 core $C$ 新增不可行区域的概率；
- $r(C)$ 表示从求解器返回的原始 core 得到 $C$ 需要增加多少次求解调用。

$H$ 不是最终还需要输出的测试数。若还需要输出 $n$ 个测试，而候选输入成为合法测试的概率约为 $Z$，那么可以粗略取 $H\approx n/Z$；实际系统也可以根据此前的接受率持续更新这个估计。

在接下来的 $H$ 个候选输入中，预计有 $H\cdot\Delta_\pi(C\mid U)$ 个会命中这个新增区域。缓存 $C$ 后，每次命中都能省去一次可行性求解。因此，预计能够节省的净调用次数为

$$
J_H(C\mid U)
=H\cdot\Delta_\pi(C\mid U)-r(C).
$$

例如，一个候选 core 能新增覆盖 $8\%$ 的先验概率质量，提炼它需要额外调用求解器 $12$ 次。如果之后还会产生约 $1000$ 个候选输入，那么预计可以避免 $80$ 次查询，净节省为 $80-12=68$ 次；如果之后只剩约 $100$ 个候选输入，则预计只能避免 $8$ 次查询，净收益为 $8-12=-4$ 次，不值得继续提炼。

这种计算把一次性的提炼成本与后续反复命中的收益放在一起衡量。相应的优化目标是

$$
C_H^*\in\operatorname*{arg\,max}_{C\subseteq A_x}
J_H(C\mid U)
\quad\text{s.t.}\quad R\land C\text{ is UNSAT}.
$$

其中 $C_H^*$ 表示在预计还会产生 $H$ 个候选输入时，净节省最大的任意 core。求解器最初返回的 core 也属于候选，并且它尚未产生额外提炼调用，因此对应的 $r(C)$ 为零。只有继续泛化后的 $J_H$ 高于直接缓存当前 core 的 $J_H$，额外提炼才值得进行；否则算法应停止提炼，保留当前结果。

#### 以运行时间衡量

调用次数并不总能准确代表成本。一次困难的求解可能持续很久，而一次缓存匹配通常很快；缓存越来越大后，匹配本身也会产生开销。为此，令：

- $\widehat c_{\mathrm{solve}}$ 表示一次可行性查询的估计平均耗时；
- $\widehat c_{\mathrm{refine}}(C)$ 表示得到 core $C$ 所需的估计总提炼时间；
- $\widehat c_{\mathrm{lookup}}(C)$ 表示加入 $C$ 后，每个候选输入新增的估计缓存匹配时间。

以时间衡量的预计净收益为

$$
J_H^{\mathrm{time}}(C\mid U)
=H\cdot\Delta_\pi(C\mid U)\cdot \widehat c_{\mathrm{solve}}
-\widehat c_{\mathrm{refine}}(C)-H\cdot\widehat c_{\mathrm{lookup}}(C).
$$

第一项是未来命中该区域预计省下的求解时间，后两项分别是当前提炼成本和未来缓存匹配成本。这个目标说明了一个简单事实：高概率区域和长时间采样更值得精细泛化；样本批次很小、区域很少重复或缓存查询已经很贵时，直接保存原始 core 可能更合适。

## 新算法比基线减少多少求解调用

设算法 $A$ 为本文的概率质量引导方法，算法 $B$ 为任一基线，例如 full no-good、原始 core、MUS 或最小基数 core。两种算法都从固定先验 $\pi$ 独立产生候选输入，并且只缓存经过 UNSAT 证明的不可行区域。

在第 $t$ 个候选输入产生前，令 $U_t^A$ 和 $U_t^B$ 分别表示两种算法已经缓存的不可行区域；令 $r_A(H)$ 和 $r_B(H)$ 分别表示它们在前 $H$ 个候选输入期间用于 core 提炼的求解调用总数；令 $Q_A(H)$ 和 $Q_B(H)$ 表示包括可行性检查和 core 提炼在内的求解调用总数。

**Proposition 1（相对求解调用收益）**：在上述条件下，算法 $A$ 相对算法 $B$ 在前 $H$ 个候选输入中减少的期望求解调用次数为

$$
\mathbb E[Q_B(H)-Q_A(H)]
=\sum_{t=1}^{H}
\mathbb E\!\left[\pi(U_t^A)-\pi(U_t^B)\right]
-\mathbb E\!\left[r_A(H)-r_B(H)\right].
$$

因此，当且仅当右侧大于零时，算法 $A$ 使用的期望求解调用次数少于算法 $B$。

**证明**：对算法 $K\in\{A,B\}$，令 $I_t^K$ 表示它是否需要为第 $t$ 个候选输入执行可行性求解：需要时 $I_t^K=1$，命中缓存而直接拒绝时 $I_t^K=0$。在候选输入产生前，$U_t^K$ 已由此前的运行历史确定；新的候选输入独立服从 $\pi$，所以

$$
\mathbb E[I_t^K\mid U_t^K]
=\Pr_\pi[X_t\notin U_t^K\mid U_t^K]
=1-\pi(U_t^K).
$$

再对缓存本身的随机性取期望，得到

$$
\mathbb E[I_t^K]
=1-\mathbb E[\pi(U_t^K)].
$$

前 $H$ 个候选输入对应的总调用次数为

$$
Q_K(H)=r_K(H)+\sum_{t=1}^{H}I_t^K.
$$

因此

$$
\mathbb E[Q_K(H)]
=\mathbb E[r_K(H)]
+\sum_{t=1}^{H}\left(1-\mathbb E[\pi(U_t^K)]\right).
$$

分别代入 $K=A$ 和 $K=B$ 并相减，即得命题中的等式。$\square$

这个 Proposition 是精确的收益分解式，不是新算法自动优于基线的性能保证。它说明只要给定两种算法实际形成的缓存轨迹和提炼成本，就能计算两者相差多少次期望求解调用；但它本身没有证明概率质量引导算法一定能获得更大的累计覆盖，也没有给出相对于最优策略的近似比。

第一项是两种算法在整个运行过程中累计覆盖概率质量的差异，第二项是算法 $A$ 相对算法 $B$ 多付出的提炼成本。它说明，最终缓存的大小并不足以评价算法：越早学到高概率不可行区域，它在后续采样中产生的收益越大。对于满足 $U_t^B\subseteq U_t^A$ 的基线，第一项还可以写成

$$
\sum_{t=1}^{H}
\mathbb E\!\left[\pi(U_t^A\setminus U_t^B)\right],
$$

即新算法相对基线累计新增的覆盖质量。这个收益超过额外提炼调用时，新算法才真正优于基线。

## 预算化 core 泛化算法

### 具有近似证书的 MassCore

简单的贪心删除可以快速得到安全 core，却不能在一般情况下保证接近质量最优解。为了获得可证明的近似质量，可以对 core 子集空间执行最佳优先的分支定界搜索（best-first branch-and-bound）。下文把这个版本称为 Certified MassCore。

对当前缓存 $U$，记候选 core 的目标值为

$$
f_U(C):=\Delta_\pi(C\mid U),
$$

并令

$$
\mathrm{OPT}_U
:=\max_{C\subseteq A_x}\left\{f_U(C)\mid R\land C\text{ is UNSAT}\right\}.
$$

一个搜索节点写成 $(I,J)$：$I$ 是确定保留的绑定，$J$ 是尚未决定是否保留的绑定。该节点包含所有满足

$$
I\subseteq C\subseteq I\cup J
$$

的候选 core。因为增加绑定只会缩小区域，所以对节点中的任意 $C$ 都有

$$
G(C)\subseteq G(I),
\qquad
f_U(C)\le f_U(I).
$$

因此，$f_U(I)$ 是这个节点中任何候选解都不能超过的质量上界。算法从根节点 $(\varnothing,A_x)$ 开始，用求解器返回的原始 core $C_0$ 初始化已知可行解，并始终优先展开质量上界最大的节点。若实现只搜索 $(\varnothing,C_0)$，则所有最优性和近似保证都必须相应限制为 $C_0$ 的子集，不能声称覆盖全部 $A_x$：

1. 用 $C_0$ 初始化当前最好解；
2. 若 $R\land(I\cup J)$ 为 SAT，则该节点不含任何 UNSAT 子集，直接剪枝；
3. 若 $R\land I$ 为 UNSAT，则 $I$ 已经是该节点内质量最大的可行解，用它更新当前最好解并结束该节点；
4. 否则选择一个 $a\in J$，分别建立保留 $a$ 和删除 $a$ 的两个子节点；
5. 达到求解调用预算后停止；尚未完成的节点仍保留在搜索队列中，由当前最好 core 和队列中所有节点的上界给出全局界。

令 $C_B$ 是使用至多 $B$ 次额外求解调用后得到的当前最好 core，令

$$
L_B=f_U(C_B)
$$

是已经找到的最好质量。令 $V_B$ 是 $L_B$ 与所有尚未搜索节点质量上界中的最大值。若搜索队列为空，则取 $V_B=L_B$。

**Proposition 2（任意预算下的近似保证）**：当区域质量由精确概率查询得到时，任意预算 $B$ 下都有

$$
L_B\le \mathrm{OPT}_U\le V_B.
$$

当 $V_B>0$ 时，算法返回的 core 满足

$$
f_U(C_B)
\ge \alpha_B\,\mathrm{OPT}_U,
\qquad
\alpha_B:=\frac{L_B}{V_B}.
$$

若 $V_B=0$，则 $\mathrm{OPT}_U=0$，当前缓存已经覆盖所有候选 core 能够新增的概率质量。

**证明**：$C_B$ 始终经过 UNSAT 验证，所以它是原优化问题的可行解，因而 $L_B\le\mathrm{OPT}_U$。尚未检查的每个候选 core 都属于某个未搜索节点，而该节点的 $f_U(I)$ 是它的上界；已经剪枝的节点或者不含 UNSAT core，或者已经由节点内质量最大的可行解 $I$ 处理。因此，最优解不可能超过 $V_B$，即 $\mathrm{OPT}_U\le V_B$。当 $V_B>0$ 时，

$$
f_U(C_B)=L_B
=\frac{L_B}{V_B}V_B
\ge\frac{L_B}{V_B}\mathrm{OPT}_U.
$$

故近似比至少为 $\alpha_B=L_B/V_B$。$\square$

这个保证是可随时计算的实例证书。算法可以在达到调用预算时停止，也可以在 $\alpha_B$ 达到用户要求的近似比例时停止。它适用于相关先验和已有缓存重叠，前提是 `Distribution` 能精确计算 $f_U(I)$；若质量来自 Monte Carlo 估计，则必须使用同时成立的置信上下界，才能把结论改写成高概率近似保证。

这个结果不意味着任意固定预算 $B$ 都能得到统一的常数近似比。一般 core 子集空间包含最小基数 MUS 等困难问题；没有额外结构时，$\alpha_B$ 可能在搜索早期仍然很小。证书的意义在于如实量化当前解离最优解还有多远，而不是预先假定贪心删除具有并不存在的保证。

### 独立先验下的对数代价证书

当 $U=\varnothing$ 且各输入变量相互独立时，对绑定 $a_i=(X_i=x_i)$ 定义

$$
w_i=-\log\pi_i(x_i).
$$

令 core 的总对数代价为

$$
W(C):=\sum_{a_i\in C}w_i.
$$

此时

$$
f_\varnothing(C)=\exp\!\left(-W(C)\right),
$$

所以最大化 core 的概率质量等价于寻找总权重最小的 UNSAT 子集。可以使用 weighted OUS／implicit hitting set 搜索维护最优代价的下界 $\underline W_B$ 和当前 UNSAT core 代价的上界 $\overline W_B$。若 $C_B$ 是当前 core，$C^*$ 是质量最优 core，则

$$
\frac{f_\varnothing(C_B)}{f_\varnothing(C^*)}
=\exp\!\left[-\bigl(W(C_B)-W(C^*)\bigr)\right]
\ge
\exp\!\left[-\bigl(\overline W_B-\underline W_B\bigr)\right].
$$

因此，对数代价差 $\varepsilon_B=\overline W_B-\underline W_B$ 直接给出概率质量近似比 $e^{-\varepsilon_B}$。若希望至少达到比例 $\alpha$，只需在

$$
\overline W_B-\underline W_B\le-\log\alpha
$$

时停止。这一特例可以复用成熟的最优不可满足子集算法，也适合作为通用 branch-and-bound 实现的正确性基线。

### 快速的贪心删除

大实例可以保留原来的删除式 MassCore 作为快速模式。从原始 core $C_0$ 开始，每次估计删除一个绑定带来的新增质量，优先尝试收益最大的删除；仅当 $R\land(C\setminus\{a\})$ 再次被证明为 UNSAT 时才永久删除 $a$。达到预算，或预计收益不足以补偿下一次求解时停止。

这个算法在任意预算下都会返回安全 core，但一般没有固定近似比。论文应在可枚举的小实例上用 Certified MassCore 给出的 $\mathrm{OPT}_U$ 或 $\alpha_B$ 评价贪心解，在大实例上报告质量、提炼调用和后续缓存命中。不能把安全性误写成近似最优性。

### 区域扩张 RegionGrow

仅删除等值假设只能得到柱状区域。Tapas 已有 `points` 和 `range`，可以定义一个更一般的区域语言 $\mathcal L$；其中每个 $G\in\mathcal L$ 都是 $\mathcal X$ 的子集，并且可以由这些限制表达。给定当前失败输入 $x_0\in F^c$，区域泛化目标为：

$$
G^*\in\operatorname*{arg\,max}_{G\in\mathcal L}\Delta_\pi(G\mid U)
\quad\text{s.t.}\quad x_0\in G,\;G\cap F=\varnothing.
$$

这里 $G^*$ 表示区域语言 $\mathcal L$ 中满足安全条件、且未覆盖概率质量最大的任意区域。

例如把 `quantity == 3` 逐步扩为 `quantity in range(1, 5)`，或把一个枚举值扩为 `points(Type, a, b)`。算法每次选择预计增加质量最大的边界扩张，并仅在扩张后的整个区域仍为 UNSAT 时接受。这能处理大整数域中单点几乎不会重复的问题。

这一层与 generalized no-good、abstract constraint learning 很接近，创新风险比删除式目标更高。比较稳妥的论文顺序是先把“质量最优假设 core”做扎实，把区域扩张作为可选增强和消融项；如果要把 RegionGrow 升为主贡献，必须补充区域语言、复杂度、近似保证以及与已有 generalized no-good 的直接比较。

### 缓存管理

core 数量增长后，查询和内存会反过来成为瓶颈。至少需要：

- 删除被新区域包含的旧区域；
- 用 trie、BDD 或按变量倒排的索引做命中查询；
- 以边际质量、命中频率和查询成本决定保留哪些区域；
- 计算候选区域相对当前并集的边际质量，避免重复学习；
- 把 core 提炼预算和 cache 容量纳入消融实验。

如果缓存最多保留 $k$ 个区域，还可以得到一个固定的近似保证。设 $\mathcal V$ 是已经经过 UNSAT 验证的有限候选区域集合。对任意 $S\subseteq\mathcal V$，定义这些区域共同覆盖的概率质量

$$
h(S)=\pi\!\left(\bigcup_{G\in S}G\right).
$$

$h$ 是单调次模函数：加入一个区域不会减少覆盖；已有区域越多，同一个新区域能够增加的覆盖越少。令贪心算法每次选择使 $h(S\cup\{G\})-h(S)$ 最大的候选区域，直到选满 $k$ 个。

**Proposition 3（有限缓存的覆盖保证）**：设 $S_{\mathrm{greedy}}$ 是贪心算法选择的至多 $k$ 个区域，$S^*$ 是 $\mathcal V$ 中覆盖质量最大的至多 $k$ 个区域，则

$$
h(S_{\mathrm{greedy}})
\ge
\left(1-\left(1-\frac1k\right)^k\right)h(S^*)
\ge
\left(1-\frac1e\right)h(S^*).
$$

**证明**：令 $S_i$ 是贪心算法选择完 $i$ 个区域后的集合。由次模性，最优集合 $S^*$ 中至多 $k$ 个区域相对 $S_i$ 的边际收益之和，至少覆盖当前差距 $h(S^*)-h(S_i)$。因此其中至少有一个区域的边际收益不小于该差距的 $1/k$；贪心选择的收益只会更大，所以

$$
h(S^*)-h(S_{i+1})
\le
\left(1-\frac1k\right)
\bigl(h(S^*)-h(S_i)\bigr).
$$

从 $S_0=\varnothing$ 递推 $k$ 次即可得到结论。$\square$

这个 $1-1/e$ 保证适用于任意联合先验，因为它只使用概率测度对集合并集的次模性。不过，它比较的是同一个已验证候选集合 $\mathcal V$ 中的缓存选择，不保证算法已经发现了全局最好的不可行区域。它不能与单次 core 证书直接相乘得到完整在线保证；后文分别分析在线选择损失、区域发现损失和额外验证成本。

例如，若缓存选择完成后还会产生 $H$ 个候选输入，构建贪心缓存使用了 $r_{\mathrm{greedy}}$ 次额外求解调用，那么相对不使用缓存，它带来的期望净调用节省至少为

$$
H\left(1-\frac1e\right)h(S^*)-r_{\mathrm{greedy}}.
$$

若基线从同一候选集合中选择了缓存 $S_B$，并使用 $r_B$ 次额外求解调用，则贪心方法相对该基线的期望调用节省至少为

$$
H\left[
\left(1-\frac1e\right)h(S^*)-h(S_B)
\right]
-\left(r_{\mathrm{greedy}}-r_B\right).
$$

当这个下界为正时，可以在不依赖实验均值的情况下保证贪心缓存优于该基线；下界不为正只表示现有保证不足以判定，不能反推出贪心方法一定更差。

## 完整在线算法：Online MassCore

前面的 Certified MassCore 解决一次失败查询如何泛化。本节把它接入持续采样：失败查询产生搜索任务，后续采样轮次逐步推进这些任务；已经证明安全的区域立即用于拒绝后续候选。算法不等待泛化完成，也不为每次失败重新开始一遍搜索。

第一版采用**质量优先搜索、公平轮转和确定的累计预算**。这是一套明确的组合算法；概率质量用于安排搜索，公平轮转避免饥饿，预算控制额外成本。它不需要预测某次验证成功的概率，也不声称这种调度在所有实例上最优。

### 输入、输出与适用范围

输入是规则 $R$、有限输入域 $\mathcal X$ 上的先验 $\pi$、希望输出的样本数 $n$，以及两个调度参数：$\beta>0$ 控制额外求解预算，整数 $q\ge2$ 控制公平轮转频率。默认可取 $\beta=1,q=4$；这是可复现的初始配置，不是理论最优参数。

第一版要求以下能力：从 $\pi$ 独立采样；计算等值绑定区域及其有限并集的精确概率质量；对有限域约束完成 SAT／UNSAT 判定。联合分布允许变量相关。最简单的参考实现可以枚举有限概率表计算质量，因此这些接口有可执行的实现，并非依赖尚未定义的概率 oracle；大域上的高效实现另行评估。

输出是按出现顺序接受的 $n$ 个业务输入及其可选 witness，允许重复。业务输入服从前文的条件分布 $\mu$，witness 不附带概率分布保证。只有 $Z>0$ 时才承诺最终得到 $n$ 个样本。可另设原始候选数上限；达到上限后返回当前前缀和未完成状态，不能把它说成已生成 $n$ 个样本，也不能声称“条件于本次成功完成”的批次仍有同样分布。

本节不启用 RegionGrow、不限制缓存容量、不改变先验、不使用估计质量代替精确质量。它们可以作为独立扩展，不能在引入后直接沿用本节全部保证。

### 持久状态与安全缓存

算法维护候选计数 $t$、已接受样本、累计额外求解次数 $r$、安全区域缓存及其并集 $U$、搜索队列和已创建任务的完整绑定键。开始时计数为零，集合为空。所有状态仅对固定的 $R$、变量域和 $\pi$ 有效；规则或定义域改变时重新开始，不能复用旧安全证明。

缓存存储等值绑定 core 及其 UNSAT 证据来源。若 $C_1\subseteq C_2$，则 $G(C_2)\subseteq G(C_1)$；插入 $C_1$ 时可删除被它包含的 $C_2$。这些清理不改变缓存并集，因此 $U$ 始终单调扩大。缓存匹配先用直接扫描，索引只改变实现成本。第一版不按命中频率驱逐区域。

一次业务查询证明完整绑定 $A_x$ 不可行后，$G(A_x)$ 已经安全，可以立即缓存。若同一次查询还能返回 assumption core $C_0\subseteq A_x$，则缓存更大的 $G(C_0)$；否则令 $C_0=A_x$。不为获取较小的初始 core 隐藏额外调用：需要另行求解的提取工作必须计入 $r$。

随后为 $A_x$ 创建一次任务，以 $(\varnothing,A_x)$ 为搜索根，以 $C_0$ 为已知安全结果。缓存原始 core 不意味着只搜索它的子集；根仍包含本次输入的全部绑定。任务按完整绑定去重。

### 一次搜索如何暂停与恢复

每个节点保存 $(I,J)$、创建序号，以及两个端点查询的已知结果。节点表示所有 $I\subseteq C\subseteq I\cup J$，优先级为

$$
b_U(I,J)=\pi(G(I)\setminus U).
$$

节点按以下状态机推进，每个调度步最多执行一次尚未完成的求解查询：

1. 若 $b_U(I,J)=0$，关闭节点：它的任何后代都不能增加正概率覆盖。
2. 若最大绑定集 $I\cup J$ 的结果未知，查询 $R\land(I\cup J)$。若为 SAT，关闭节点；若为 UNSAT，记录结果，保留节点等待下一步。
3. 最大绑定集已知 UNSAT 后，若最小绑定集 $I$ 的结果未知，查询 $R\land I$。若为 UNSAT，将 $G(I)$ 加入缓存并关闭节点；若为 SAT，进入分支步骤。
4. 选择 $J$ 中声明顺序最前的绑定 $a$，建立保留分支 $(I\cup\{a\},J\setminus\{a\})$ 和删除分支 $(I,J\setminus\{a\})$，关闭父节点。孩子获得新的创建序号，并继承适用于同一端点的已知结果。

相同端点不重复查询；根的最大绑定集结果由业务查询提供。若 $J=\varnothing$，两个端点相同，复用结果即可关闭，不再分支。剪枝、插入和分支不消耗求解预算，但都计入实际运行时间。只要有限域查询最终完成，这个有限状态机就可以执行。

每次缓存变化后，重新计算待选节点的优先级。参考实现直接扫描全部待处理节点，避免使用过期质量排序。旧质量作为上界仍安全，但不能据此声称选中了当前最大新增质量的节点。

这里与单次 MassCore 有一个区别：在线搜索把每个已验证区域立即发布到缓存，因而目标随 $U$ 改变。不得直接把一个已变化的任务历史解释为 Proposition 2 中固定 $U$ 的近似证书。单次证书实验仍使用冻结缓存的搜索；在线实验记录覆盖与调用开销。

### 预算与跨任务调度

经过 $t$ 个原始候选后，允许的累计额外求解次数为

$$
B(t)=\lfloor\beta\sqrt t\rfloor.
$$

这不是对“预计剩余样本数”的估计。它是一个确定的保守预算：随着采样持续，发现工作仍能继续，但额外调用占原始候选数的比例趋于零。$t$ 包括缓存命中后直接拒绝的候选，不能只统计实际送入求解器的输入。

每轮业务候选处理完后，若还需要继续生成样本，就在 $r<B(t)$ 且队列非空时推进搜索。未使用的预算可以留给以后。每执行一次额外查询，$r$ 加一。

每第 $q$ 次额外查询选择创建序号最小的未完成节点，其余查询选择当前 $b_U$ 最大的节点，平局仍按创建序号处理。节点在端点查询之间保留原创建序号。没有待查询端点的节点先完成剪枝或分支，再选择下一节点。这使公平调度真正作用于尚未完成的工作，而不会被无须求解的操作消耗。

质量优先部分把预算投向可能覆盖更多后续输入的搜索分支；公平部分让质量较低的旧任务也能推进。这里的 $b_U$ 是可达到收益的上界，不是下一次查询的期望收益。算法没有把二者混同，也没有据此采用未经定义的盈亏停止条件。

### 完整流程

```text
OnlineMassCore(R, π, n, β = 1, q = 4):
    初始化空缓存、任务队列、输出和计数 t = r = 0
    while 输出数量 < n:
        x ← 从 π 独立采样
        t ← t + 1
        if x 未命中安全缓存:
            查询 R ∧ A_x                       // 一次业务求解
            if SAT:
                输出 (x, witness)
            else if UNSAT:
                缓存本次已证明安全的 core，或完整绑定 A_x
                若任务未创建，加入以 A_x 为根的可恢复搜索任务
            else:
                结束并报告未完成                 // 不把 UNKNOWN 当作拒绝
        if 输出数量 == n 或已达原始候选上限:
            返回当前输出及完成状态
        while r < floor(β sqrt(t)) 且仍有待处理节点:
            完成无需查询的节点操作
            若已无待查询节点，结束本轮发现工作
            按质量优先／公平轮转选择一个待查询节点
            执行其下一次端点查询；r ← r + 1
            保存结果，发布已证明的安全区域，更新队列
    返回输出及完成状态
```

理论版本的验证接口最终返回 SAT 或 UNSAT。工程实现遇到超时或 UNKNOWN 时保留该节点，不得剪枝或发布未经证明的区域，并报告发现工作未完成；继续重试需要单独计入预算。若业务查询返回 UNKNOWN，应停止或等待同一候选被判定，不能跳过它继续采样，否则会引入与求解难度相关的偏差。以下有限完成结论不适用于无限次 UNKNOWN。

### 可以直接证明的性质

**Proposition 7（在线组合算法的安全性、预算与有限域收敛）**：在上述精确质量、有限域、确定判定假设下，Online MassCore 满足：

1. 缓存始终包含于 $F^c$。不施加外部截断、且 $Z>0$ 时，输出输入是来自 $\mu$ 的独立样本。
2. 对任意前 $T$ 个原始候选，额外求解次数满足 $r(T)\le B(T)$。与无缓存 rejection 在同一候选序列上的业务调用数 $Q_{\rm rej}(T)=T$ 比较，算法总调用数满足路径上的界

$$
Q_{\rm OMC}(T)-Q_{\rm rej}(T)\le\lfloor\beta\sqrt T\rfloor.
$$

3. 对持续运行的采样流，每个已创建任务在有限时间内完成或因没有剩余概率质量而关闭；并且

$$
\pi(F^c\setminus U_T)\longrightarrow0
\quad\text{几乎必然成立}.
$$

这里 $U_T$ 是处理完第 $T$ 轮及其发现工作后的缓存并集。“持续运行”指去掉固定输出数的终止条件，或持续接收更多样本请求。

**证明**：初始缓存为空。每次插入都来自业务 UNSAT 结论或端点 UNSAT 验证，故归纳得到安全性。沿同一独立候选流，缓存命中的点本来就会被 rejection 拒绝；其他点经完整求解作出相同接受决定，因此两者得到同一接受子序列。

预算检查直接保证 $r(T)\le B(T)$。每个候选最多进行一次业务求解，额外调用仅为 $r(T)$，所以第二项路径界成立。该界只计算调用次数，不约束单次求解或质量计算的耗时。

设输入变量数为 $m$。每个完整绑定只创建一个任务，有限域中任务数至多 $|\mathcal X|$；每棵二叉搜索树至多有 $2^{m+1}-1$ 个节点，每个节点至多两次端点查询。因此全部可创建的任务只有有限次验证工作。$B(t)\to\infty$ 且公平查询定期发生，每个节点前面只有有限个创建序号更小的节点，故持续存在的任务不会饥饿。零质量剪枝不会遗漏任何可增加正质量的后代。

最后，任意满足 $\pi(x)>0$ 的不可行输入都会在独立无限候选流中被遇到，首次遇到时要么已经被缓存覆盖，要么业务求解将它所在的安全区域加入缓存。正概率支持有限，缓存并集单调，故所有正概率不可行输入最终都被覆盖，得到第三项质量收敛。$\square$

第三项的覆盖收敛仅靠缓存完整失败输入就能成立，不能作为概率质量引导的独有贡献。算法的价值需要体现在达到相同覆盖所需的候选数、额外调用数或运行时间上；公平性也只保证最终推进，不给出快速发现的统一速率。

### 如何与旧算法比较

对于任意基线，在相同 $R,\pi$ 和原始候选流上比较。令 $U_t^{\rm OMC}$、$U_t^{\rm old}$ 分别为处理第 $t$ 个候选之前的缓存，定义累计覆盖优势

$$
D_T=\sum_{t=1}^T\mathbb E\left[\pi(U_t^{\rm OMC})-\pi(U_t^{\rm old})\right].
$$

令 $r_{\rm old}(T)$ 为基线的额外发现调用数。由 Proposition 1 和本节预算上界，

$$
\mathbb E[Q_{\rm old}(T)-Q_{\rm OMC}(T)]
\ge D_T-\beta\sqrt T+\mathbb E[r_{\rm old}(T)].
$$

因此，在一个给定采样长度上，累计覆盖优势超过额外发现成本，就有严格的期望调用收益。若在所研究的长度范围内另能证明 $D_T\ge\gamma T$，其中 $\gamma>0$，则忽略基线自身发现成本后，$T>(\beta/\gamma)^2$ 足以使该下界为正。这是带前提的推论，不是本算法已经保证 $\gamma>0$。

特别是，有限域、无限缓存下，raw-core 基线也会逐渐覆盖全部正概率不可行输入。因此不能直接搬用有限容量分离例子的永久线性质量差距；本版本需要比较发现过程中的累计优势。后文 Proposition 4—6 分析的有限候选、有限容量选择器是另一种扩展，不是本节调度器的收敛证明。

为了单独评价概率质量排序，必须加入一个与本算法共享累计预算、缓存规则和搜索状态机的对照，只将优先级改为 FIFO 或绑定数量。两者各自发现区域，所有额外调用都计费。这样才是在检验质量引导发现，而不是比较不相等的计算预算。

### 复用的算法与实现边界

本版本复用分支定界、可恢复搜索和公平轮转；独立先验且冻结空缓存的局部问题可用 weighted OUS 作为替代后端。OUS 的来源见[最优不可满足子集搜索](https://arxiv.org/abs/2105.11763)。这里采用的在线调度是本文明确给出的组合方案，不把它表述为该文已有的算法或定理。

后续若要让预算随预期收益自适应，可采用[计算选择与计算价值框架](https://arxiv.org/abs/1207.5879)，但需要另外定义对验证结果的信念、成本与后续信息价值。它不属于当前默认流程。有限缓存、概率估计、RegionGrow 也分别实现和评估，避免把多个尚未验证的策略同时放进主算法。

参考实现应拆为五个内部部件：候选采样与接受流程、可追踪的验证接口、区域质量与缓存、可恢复的 core 搜索、预算与调度器。日志逐轮记录候选数、业务／发现调用、缓存质量、所选节点、调度原因和安全证据来源；不把这些内部参数强加给业务测试的表达式。本文在此完成算法规格，尚不表示这些运行时代码已经实现。

## 单次改进与在线比较：可证明的结果

下面把概率质量引导分成两个操作：生成经过 UNSAT 验证的候选区域，以及在候选区域中选择应使用的结果。前者负责发现，后者负责利用。两者可以共享历史，但理论不能用选择阶段的保证代替发现阶段的保证。

本节中的求解调用专指对业务规则执行的可行性检查及区域 UNSAT 验证。概率估计、区域匹配和组合选择的计算时间另行统计；如果组合选择本身调用优化求解器，其调用和耗时也须单列。减少业务可行性查询不自动意味着运行时间更短。

### 公平的比较条件

单次实验固定同一个 $R,\pi,U,x$ 和候选表达空间；双方获得相同的初始查询结果，并记录全部额外验证调用。在线实验固定独立同分布的候选输入序列、缓存容量、区域语言和验证接口。先让双方共享候选区域发现流程，以比较选择策略；再开放各自的发现策略，单独测量由发现过程产生的差距。不能让新算法看到旧算法没有获得的 core，却把差异全部归功于概率排序。

普通 no-good 在文献中可以是广义区域。本文的“失败点基线”特指仅缓存完整赋值，不能把对该弱基线的结论泛化到所有 no-good 算法。

### 单次选择：有限样本下的近似和严格改进

固定当前缓存 $U$，令 $\mathcal C$ 是有限个已验证 UNSAT 的候选 core，$M=|\mathcal C|\ge1$。基线 core $C_{\mathrm{old}}$ 也包含在 $\mathcal C$ 中。先固定这些对象，再独立抽取 $N$ 个参考输入 $Z_1,\ldots,Z_N\sim\pi$。定义

$$
f(C)=\pi(G(C)\setminus U),\qquad
\widehat f_N(C)=\frac1N\sum_{j=1}^N
\mathbf1[Z_j\in G(C)\setminus U].
$$

这些参考输入只用于区域匹配，不需要查询业务规则。令 $\widehat C$ 是经验质量最大的候选，$C^*$ 是真实质量最大的候选。有限候选集可以直接枚举求最大值，因此这里没有把尚未求解的优化误差隐藏在假设中；代价是 $O(NM)$ 次匹配，而不是常数时间。

**Proposition 4（单次选择保证）**：给定失败概率 $\delta\in(0,1)$，令

$$
\varepsilon_N=\sqrt{\frac{\log(2M/\delta)}{2N}}.
$$

以至少 $1-\delta$ 的概率，以下结论同时成立：

$$
f(\widehat C)\ge f(C^*)-2\varepsilon_N,
$$

$$
f(\widehat C)-f(C_{\mathrm{old}})
\ge \widehat f_N(\widehat C)-\widehat f_N(C_{\mathrm{old}})
-2\varepsilon_N.
$$

**证明**：对每个固定 $C$，Hoeffding 不等式给出
$\Pr[|\widehat f_N(C)-f(C)|>\varepsilon]\le2e^{-2N\varepsilon^2}$。
对 $M$ 个候选取并集界，得到同时成立的误差界
$\sup_C|\widehat f_N(C)-f(C)|\le\varepsilon_N$。
在该事件上，

$$
f(\widehat C)\ge\widehat f_N(\widehat C)-\varepsilon_N
\ge\widehat f_N(C^*)-\varepsilon_N
\ge f(C^*)-2\varepsilon_N.
$$

分别对新旧结果使用下界和上界，得到第二个结论。$\square$

设新旧算法额外验证调用的差为 $d$，接下来保持两个缓存不变，并处理 $H$ 个新的独立候选输入。于是以同样置信度，新算法相对基线的条件期望净调用节省至少为

$$
H\left[
\widehat f_N(\widehat C)-\widehat f_N(C_{\mathrm{old}})
-2\varepsilon_N
\right]-d.
$$

这是可以由运行结果计算的严格改进证书：下界为正才能认证改进。已经花费但未产生有效 core 的验证调用也计入 $d$。这里认证的是未来调用数的条件期望，不是保证每一次未来随机运行都节省这么多。

若要相对于完整绑定 $A_x$ 的所有 UNSAT 子集保证近似最优，可以枚举至多 $2^m$ 个子集并验证，其中 $m=|A_x|$；这样比较空间完整，但最坏验证成本指数增长。若只使用已发现的候选集，保证就只相对于该集合。统计误差收敛率不能消除这个计算难点。

### 一个严格区分最小 core 与质量最优 core 的问题族

考虑三个相互独立的 Bool 变量 $a,b,c$，满足

$$
\Pr[a=1]=\theta,\qquad
\Pr[b=1]=\Pr[c=1]=\frac12,\qquad 0<\theta<\frac14,
$$

以及规则

$$
R(a,b,c)=(\neg a)\land(\neg b\lor\neg c).
$$

对失败输入 $x=(1,1,1)$，恰有两个包含关系最小的绑定 core：

$$
C_1=\{a=1\},\qquad C_2=\{b=1,c=1\}.
$$

空缓存下，$f(C_1)=\theta$，$f(C_2)=1/4$。最小基数方法必然选择 $C_1$；质量最优方法选择 $C_2$。在双方共享这两个候选和验证成本的条件下，新方法对后续 $H$ 个候选输入严格节省

$$
H\left(\frac14-\theta\right)
$$

次期望求解调用。缓存命中率之比为 $1/(4\theta)$，可随 $\theta\to0$ 任意增大；这是命中率的比例，不能称为运行速度获得无界加速。两种方法的每轮可行性调用率分别为 $1-\theta$ 和 $3/4$。

这个例子只使用独立 Bool、合取和二元析取，没有依赖异常复杂的规则或相关分布。它证明最小基数与采样收益可以严格分离；它不证明任意 MUS 提取算法都选错，因为 MUS 算法也可能返回 $C_2$。对于最少绑定优先且容量为一个区域的在线缓存，这个差距会持续；若两种方法最终都无限制缓存两个区域，长期差距可能消失。

### 在线算法：复用全部候选输入的反馈

在线版本把每个已生成输入用于更新区域命中统计。它必须使用所有候选输入，包括已经命中缓存而被拒绝的输入；只使用交给求解器的输入，会得到经过选择的样本，下面的统计结论不再适用。

预先固定有限区域字典 $\mathcal D$，大小为 $P$，以及缓存容量 $k\ge1$。字典可以由有限域中的绑定子集、预设区间端点和有限点集定义；不要求提前枚举或提前证明其中的区域不可行。所有至多包含 $k$ 个区域的缓存组成固定类

$$
\mathcal S=\{S\subseteq\mathcal D:|S|\le k\},\qquad
M=|\mathcal S|=\sum_{j=0}^{\min(k,P)}\binom Pj.
$$

令 $\mathcal S_t\subseteq\mathcal S$ 是第 $t$ 个输入产生前，由已经验证安全的区域组成的可用缓存集合。$\mathcal S_t$ 可以根据此前的失败和验证结果自适应增长。对缓存 $S$ 定义

$$
g_S(x)=\mathbf1\left[x\in\bigcup_{G\in S}G\right],
\qquad h(S)=\mathbb E_{X\sim\pi}[g_S(X)].
$$

在第 $t\ge2$ 轮，用全部历史候选输入计算

$$
\widehat h_{t-1}(S)=\frac1{t-1}\sum_{s=1}^{t-1}g_S(X_s),
\qquad
S_t\in\operatorname*{arg\,max}_{S\in\mathcal S_t}
\widehat h_{t-1}(S).
$$

新发现区域也要回溯匹配历史输入。第一轮任取一个可用缓存。实际实现可按块更新并使用位集合加速；下述结论先分析逐轮精确选择，可通过枚举实现，组合计算成本可能很大。若使用近似选择，必须把每轮经验优化差距计入误差，不能沿用精确结论。

### 在线收益与收敛速度

令 $S_t^*$ 是 $\mathcal S_t$ 中真实覆盖质量最大的缓存。它知道先验质量，但与在线算法拥有同样的已发现区域，因而是“当前信息下的最优选择”。记

$$
\mathcal R_T=\sum_{t=1}^T
\mathbb E[h(S_t^*)-h(S_t)]
$$

为前 $T$ 轮相对它的累计覆盖差距，期望包括历史输入及发现流程的随机性。

**Proposition 5（可用区域自适应增长时的在线界）**：在上述固定有限字典、固定联合先验和独立候选输入条件下，

$$
\mathcal R_T\le
1+2\sqrt{2T\log(2M)}
=:a_T.
$$

此结论允许变量相关、区域重叠，以及可用区域集合依赖历史数据。

**证明**：对 $n$ 个独立输入，令
$D_n=\max_{S\in\mathcal S}|\widehat h_n(S)-h(S)|$。
对固定 $S$，Hoeffding 引理给出
$\mathbb E e^{\lambda(\widehat h_n(S)-h(S))}\le e^{\lambda^2/(8n)}$；
同时处理正负两种误差并对 $M$ 个缓存求和，得到

$$
\mathbb E D_n\le
\inf_{\lambda>0}\left[
\frac{\log(2M)}{\lambda}+\frac{\lambda}{8n}
\right]
=\sqrt{\frac{\log(2M)}{2n}}.
$$

统一界覆盖预先固定的整个 $\mathcal S$，因此即使 $\mathcal S_t$ 根据相同历史数据产生，仍有逐路径不等式

$$
h(S_t^*)-h(S_t)\le2D_{t-1}.
$$

第一轮差距至多为 $1$；对其余轮取期望并使用
$\sum_{n=1}^{T-1}n^{-1/2}\le2\sqrt T$，得到结论。$\square$

于是平均每轮覆盖差距为 $O(\sqrt{\log M/T})$。这是明确的在线收敛速度，收敛对象是当前可用区域中的最优缓存。有限缓存选择的 $1-1/e$ 贪心界可以作为便宜替代，但不能把其固定比例损失省略后声称同样收敛到最优值。

现在考虑旧算法每轮使用的缓存 $S_t^{\mathrm{old}}\in\mathcal S_t$，定义它相对当前最优选择的累计差距

$$
\Gamma_T=\sum_{t=1}^T
\mathbb E[h(S_t^*)-h(S_t^{\mathrm{old}})].
$$

令 $d_T$ 为新算法减去旧算法的期望额外验证调用数，包含失败探索和区域发现。由 Proposition 1 和 Proposition 5，

$$
\mathbb E[Q_{\mathrm{old}}(T)-Q_{\mathrm{new}}(T)]
\ge \Gamma_T-a_T-d_T.
$$

所以当 $\Gamma_T>a_T+d_T$ 时，新算法严格节省期望调用。若旧策略每轮平均留下至少 $\gamma>0$ 的覆盖差距，即 $\Gamma_T\ge\gamma T$，且 $d_T=o(T)$，则新算法对充分大的 $T$ 必然严格更好，其调用优势至少为

$$
\gamma T-O(\sqrt{T\log M})-o(T).
$$

这里 $\gamma>0$ 是对某个基线的质量差距条件，不是对所有旧算法的假设。上述 Bool 问题族在两个 core 均可用且缓存容量为一时，最小基数基线具有 $\gamma=1/4-\theta$。若两个 core 自始可用、验证成本相同，则显式充分条件为

$$
T>\max\left\{\frac2\gamma,\,
\frac{32\log(2M)}{\gamma^2}\right\},
$$

因为这时 $\gamma T>1+2\sqrt{2T\log(2M)}$。因此这里不仅有收益分解，还给出了可检验的问题族、在线收敛速度和严格占优的运行长度。

### 质量存在间隔时：错误选择概率指数下降

有限区域语言还允许更快的结论。假设一个固定的已验证缓存集合从第一轮起可用，最优质量为 $h^*$。若存在次优缓存，定义最优值与所有严格次优值之间的最小间隔

$$
\rho=\min_{S:\,h(S)<h^*}\bigl(h^*-h(S)\bigr)>0.
$$

可以存在多个并列最优缓存，不要求最优解唯一。固定有限集合中只要存在次优值，这个间隔就为正；但它可能很小，界的常数不能忽略。

**Proposition 6（有间隔时的快速收敛）**：对上述精确经验选择算法，第 $t\ge2$ 轮选择严格次优缓存的概率满足

$$
\Pr[h(S_t)<h^*]
\le\min\left\{1,\,2M
\exp\left(-\frac{(t-1)\rho^2}{2}\right)\right\}.
$$

因此任意 $T$ 下，其累计期望覆盖损失都不超过与 $T$ 无关的常数

$$
\sum_{t=1}^T\mathbb E[h^*-h(S_t)]
\le
3+\frac{2(\log(2M)+1)}{\rho^2}
=:b_\rho.
$$

**证明**：如果所有经验质量误差均小于 $\rho/2$，任何严格次优缓存的经验质量都不可能超过真实最优缓存。因此次优选择必然意味着
$D_{t-1}\ge\rho/2$。
对所有缓存应用 Hoeffding 不等式和并集界，得到概率界。每轮覆盖损失至多为 $1$。令
$n_0=\lceil2\log(2M)/\rho^2\rceil$，前 $n_0$ 项各以 $1$ 上界，之后的概率以几何级数上界，并使用
$1/(1-e^{-u})\le1+1/u$（$u>0$），即可得到给出的 $b_\rho$。$\square$

若旧策略每轮保持至少 $\gamma>0$ 的质量差距，额外发现与提炼调用差至多为固定常数 $d$，则

$$
\mathbb E[Q_{\mathrm{old}}(T)-Q_{\mathrm{new}}(T)]
\ge\gamma T-b_\rho-d.
$$

因此 $T>(b_\rho+d)/\gamma$ 是一个显式的严格占优条件。它说明概率选择错误会随着观察数据积累迅速消失，而持续忽略概率的旧策略可以不断支付固定的每轮损失。这个结论适用于固定比较集合；集合不断增长而差距逐渐趋近于零时，应使用 Proposition 5。

### 区域发现如何进入完整在线保证

以上结果不要求区域发现完成后再开始采样，但没有免费解决发现问题。定义固定字典中所有安全、容量至多为 $k$ 的缓存里最优的一个为 $S^\dagger$，并定义

$$
\mathcal A_T=\sum_{t=1}^T
\mathbb E[h(S^\dagger)-h(S_t^*)].
$$

$\mathcal A_T$ 是尚未发现好区域造成的累计损失。完整差距满足

$$
\sum_{t=1}^T\mathbb E[h(S^\dagger)-h(S_t)]
\le \mathcal A_T+a_T.
$$

如果新旧算法各自发现不同的区域，可把旧算法的质量直接与新算法当前可用的 $S_t^*$ 比较，收益恒等式仍成立，但 $\Gamma_T$ 可能为负；不能再默认新算法拥有同等信息下的优势。

一种可以严格分析、但可能昂贵的完整实现，是对有限字典执行公平验证：在采样轮之间按预定顺序检查尚未验证的区域，每轮验证一个，直至全部判定，每个区域最多查询一次。若字典有 $P$ 个区域，则发现开销至多 $P$，在至多 $P$ 轮后 $\mathcal A_T$ 不再增长，并有 $\mathcal A_T\le P$。相对不承担发现成本、直接知道 $S^\dagger$ 的理想基线，总期望额外调用至多

$$
2P+a_T.
$$

前一个 $P$ 来自发现期间的覆盖损失，后一个来自区域验证。若全部安全缓存之间还满足 Proposition 6 的间隔条件，则可以进一步把该界改为 $2P+b_\rho$：发现完成后使用同样的统一误差和几何级数论证即可。于是，相对一个每轮具有质量差距 $\gamma$、不计其自身发现成本的旧策略，完整在线算法也满足

$$
\mathbb E[Q_{\mathrm{old}}(T)-Q_{\mathrm{new}}(T)]
\ge\gamma T-2P-b_\rho.
$$

这是包含区域发现开销的严格比较，但常数依赖字典规模与质量间隔，不能宣称适合任意大字典。若改用失败驱动或质量引导发现，需要另外证明它能使 $\mathcal A_T$ 和验证成本更小；目前不能仅凭搜索顺序直觉做出这一承诺。验证返回 UNKNOWN 时也不能标记为已判定；有限完成保证要求这些有限域查询均能得到确定结论。

### 理论贡献与仍待验证的部分

Proposition 4 是有限类统一收敛应用于 core 选择，Proposition 5 是相同工具用于完整反馈下的在线缓存选择；这类统计思想已有成熟基础，见[有限类经验风险最小化](https://www.cs.princeton.edu/~rlivni/cos511/lectures/lect2.pdf)和[随机环境中的 Follow-the-Leader](https://arxiv.org/abs/1301.0534)。本文在此推导的是它们在自适应安全区域池中的适用条件、与验证成本相连的调用收益，以及相对于最小基数基线的分离问题族，不能把浓缩不等式本身称为新发现。

已证明的是指定条件下的近似、收敛和严格收益；尚未证明的是质量引导发现比公平枚举更快、低成本组合近似保留同样的在线界，以及完整算法的运行时间优势。尤其不能从区域并集的次模性直接推出 UNSAT 查询的自适应次模性；后者需要额外证明，参见[Golovin 与 Krause 的自适应次模框架](https://arxiv.org/abs/1003.3967)。

## 与五类基线怎样比较

| 基线 | 行为 | 分布语义 | 论文中要回答的问题 |
|---|---|---|---|
| 普通 rejection | 每个 $x\sim\pi$ 都调用求解器 | 精确 $\mu$ | core 缓存省了多少调用和时间 |
| full no-good | 只缓存完整失败赋值 | 精确 | 泛化区域是否带来严格的新增概率质量和复用 |
| 原始 solver core | 直接缓存求解器返回的 sufficient core | 精确 | 概率引导提炼是否值得额外调用 |
| MUS／minimum core | 按包含最小或基数最小提炼 | 精确 | “小”是否真的等于高概率质量；计算成本如何 |
| SampleSearch／SIR | 在一次提案内搜索到可行解，并用权重纠偏 | 需采用其定义的权重或重采样语义 | Tapas 是否以更简单的精确条件语义换取更稳定的业务分布，并在哪些可行率下更快 |

还应加入 weighted/projected sampler 作为能力边界基线，至少在布尔或小有限域基准上比较。否则评审可能认为论文忽略了最接近的加权投影采样研究。

SampleSearch 的一次“样本生成”内部可能执行多次传播、回溯和一致性检查，不能只把外层调用记为一次。公平比较至少同时报告统一的约束 oracle 调用、求解器节点／冲突数和端到端时间；如果实现栈差异使内部调用无法统一，端到端时间和输出分布误差应成为主要指标，调用次数作为 Tapas 各消融版本之间的机制指标。

“minimum core”应明确采用哪种定义。建议同时报告：

- raw core；
- deletion MUS；
- exact minimum-cardinality core，仅用于小实例；
- exact maximum-mass core，仅用于可枚举的小实例；
- Certified MassCore，并报告预算结束时的近似证书 $\alpha_B$；
- greedy MassCore。

这样既能验证启发式离正式目标多远，也能展示 minimum-cardinality 和 maximum-mass 的实际差异。

## Rule Item 分布校准

### 最稳妥的第一版：带标签的场景分层

对一个命名 Rule Item $t$，Tapas 已经可以构造两个规则：

- 成功规则：原 Rule 全部成立；
- 精准拒绝规则：其他 Item 成立而 $t$ 不成立，即 `rules::violate(Rule, t)`。

多个拒绝原因可能重叠，因此完整系统需要把场景定义成带标签的分层，例如“成功”以及按业务顺序确定的“首个失败 Item”，或直接使用一组可行的 Item 真值向量。设一共定义了 $L$ 个场景。第 $k$ 个场景由规则 $R_k(x,y)$ 描述，其可补全输入集合为

$$
E_k=\{x\in\mathcal X\mid \exists y\in\mathcal Y:R_k(x,y)\},
\qquad k=1,\ldots,L.
$$

不同的 $E_k$ 可以重叠；此时同一个输入 $x$ 可以用于不同的场景，但场景标签和对应求解 witness 不同。如果要求输入本身唯一决定场景，则还需要额外保证这些 $E_k$ 两两不交。

用户给定场景权重 $\alpha=(\alpha_1,\ldots,\alpha_L)$，满足 $\alpha_k\ge 0$ 且 $\sum_{k=1}^L\alpha_k=1$。令随机变量 $S\in\{1,\ldots,L\}$ 表示选中的场景，则校准后的联合概率质量函数 $\rho$ 定义为：

$$
\rho(x,k)
:=\alpha_k\,\pi(x\mid E_k).
$$

这里 $\rho(x,k)$ 表示事件 $S=k$ 且 $X=x$ 的联合概率质量，而

$$
\pi(x\mid E_k)
=\frac{\pi(x)\mathbf 1[x\in E_k]}{\pi(E_k)}
$$

是先验 $\pi$ 在场景可行集 $E_k$ 上的条件概率质量。所有 $\alpha_k>0$ 的场景都必须满足 $\pi(E_k)>0$。采样时先按权重向量 $\alpha$ 抽取 $S$，再对 $R_S$ 使用前述 core-guided conditional sampler。这个定义同时满足：

1. 每次抽样落入第 $k$ 个业务场景的概率为 $\alpha_k$；如果需要有限测试集也具有精确配额，可以预先为各场景分配固定样本数；
2. 每个场景内部仍保留原始业务先验的相对概率，不会为了覆盖而任意制造不自然数据；
3. 若某个目标场景不可行，求解器可以直接报告规则冲突，而不是静默改变配额。

这比笼统的“coverage feedback 调整概率”更容易证明、更符合 Rule Item 的产品语义，也更适合首篇论文。

### 重叠边际目标

原 Rule 的条件分布 $\mu$ 只包含“全部条件成立”的输入，所以不能直接在 $\mu$ 上校准各类违反比例。需要先把一个测试对象定义为 $\omega=(k,x)$：$k$ 是场景标签，$x\in E_k$ 是该场景中的输入。所有允许测试对象构成有限集合

$$
\Omega=\{(k,x)\mid k\in\{1,\ldots,L\},\ x\in E_k\}.
$$

令 $\nu(\omega)$ 是 $\Omega$ 上的基准概率质量函数。它可以由上一节的场景混合分布 $\rho(x,k)$ 给出，也可以由另一组初始场景权重和业务先验构造。

如果用户希望同时指定 $m$ 个可能重叠的 Item 事件，可为第 $j$ 个事件定义指示特征 $f_j(\omega)\in\{0,1\}$ 和目标命中率 $\beta_j$，其中 $j=1,\ldots,m$。特征必须由测试对象 $\omega$ 唯一确定；如果某个 Item 的真假还取决于未被场景标签确定的 witness $y$，就必须先扩充测试对象或为 witness 定义概率语义。

令 $q$ 表示定义在 $\Omega$ 上的候选概率分布，并要求 $q$ 只在 $\nu(\omega)>0$ 处赋予正质量。定义从 $q$ 到 $\nu$ 的 Kullback–Leibler divergence 为

$$
D_{\mathrm{KL}}(q\Vert\nu)
=\sum_{\omega\in\Omega}q(\omega)\log\frac{q(\omega)}{\nu(\omega)}
$$

并约定 $q(\omega)=0$ 的求和项为 $0$。用 $\mathbb E_q$ 表示关于 $q$ 的期望。要求各 Item 达到目标命中率、同时尽量接近基准测试分布 $\nu$ 的优化问题为

$$
q^*=\operatorname*{arg\,min}_q D_{\mathrm{KL}}(q\Vert\nu)
\quad\text{s.t.}\quad
\mathbb E_q[f_j]=\beta_j,
\quad j=1,\ldots,m.
$$

这里 $q^*$ 表示达到最小 KL divergence 的分布。目标向量 $\beta=(\beta_1,\ldots,\beta_m)$ “可达”是指至少存在一个候选分布 $q$ 满足全部期望约束。有限域中，如果可达目标位于这些约束允许区域的相对内部，则存在一个由 $m$ 个实数组成的参数向量 $\lambda$。令 $f(\omega)=(f_1(\omega),\ldots,f_m(\omega))$，并用 $\lambda^\top f(\omega)$ 表示两个向量的内积，则解可以写成指数倾斜分布

$$
q_\lambda(\omega)
=\frac{\nu(\omega)\exp(\lambda^\top f(\omega))}{Z(\lambda)},
\qquad
Z(\lambda)=\sum_{\omega\in\Omega}\nu(\omega)\exp(\lambda^\top f(\omega)).
$$

其中 $Z(\lambda)$ 是归一化常数，$\lambda$ 的取值用于满足目标命中率。位于允许区域边界上的目标可能只能由参数极限表示，不能笼统声称总有有限的 $\lambda$。

但 I-projection、最大熵和 iterative proportional fitting 都是经典方法，这一数学形式不能当作新的理论贡献。Tapas 的价值在于把约束直接建立在 Rule Item 上、检查目标边际是否可达、用求解器采样并给出业务级诊断。第一篇论文可以把它放在扩展或未来工作，避免同时承担联合边际可行性、参数估计和近似误差证明。

## 成对反事实采样

对目标 Item $t$，令 $R_t^-(x,y)$ 表示“其他 Item 成立而 $t$ 不成立”的精准违反规则，并定义其可补全输入集合

$$
E_t^-=\{x\in\mathcal X\mid\exists y\in\mathcal Y:R_t^-(x,y)\}.
$$

先从成功场景或另一个业务分层采样锚点 $x^+$，再求解：

$$
x^-\in\operatorname*{arg\,min}_x d(x,x^+)
\quad\text{s.t.}\quad x\in E_t^-,
$$

其中 $d$ 是从两个输入映射到非负实数的用户定义业务距离；它可以通过给字段变化分配不同代价，表达哪些身份或背景字段应保持不变。$x^-$ 是距离锚点最近的精准违反输入。输出是共享同一业务背景的成功／拒绝对，更容易解释“这个条件究竟改变了什么”。

这不是严格意义上的因果效应，除非系统提供因果模型和干预语义。论文中应称为 paired counterfactual tests 或 minimally changed contrastive tests，避免把约束上的最小变化夸大为因果证明。

若将来需要概率语义，可以把成功输入集合记为 $E_+$，并分别定义 $\mu_+(x)=\pi(x\mid E_+)$ 和 $\mu_-(x)=\pi(x\mid E_t^-)$。再把成对生成定义为二者之间的耦合：在所有边缘分布分别为 $\mu_+$ 和 $\mu_-$ 的联合分布中最小化期望距离。这里的耦合是定义在输入对 $(x^+,x^-)$ 上、边缘分别等于这两个目标分布的联合分布。这会进入最优传输和反事实生成的成熟领域，理论负担较大。现阶段把成对生成作为应用更稳妥。

## 实验设计

### 研究问题

- **RQ1 正确性**：输出是否服从前文定义的目标条件分布 $\mu$？
- **RQ2 效率**：相对 rejection、full no-good、raw core、MUS、minimum core 和 SampleSearch，求解器调用、墙钟时间和吞吐量如何？
- **RQ3 目标有效性**：概率质量是否比 core 大小更能预测未来 cache hit 和摊销收益？
- **RQ4 鲁棒性**：效果如何随分布偏斜、变量相关、约束稀疏度和可行率变化？
- **RQ5 校准**：Rule Item 配额能否达到目标，同时保持分层内部的业务分布？
- **RQ6 应用**：成对反事实是否比独立成功／失败样本更小、更稳定、更容易定位目标 Item？

### 可控合成基准

至少控制以下维度，并做全因子或分层抽样实验：

- 先验偏斜：uniform、不同参数的 Zipf、长尾类别、混合分布；
- 变量相关：独立、贝叶斯网／因子图、强相关分组；
- 约束稀疏度：每个约束涉及变量数、约束图平均度、聚类系数；
- 可行率 $Z$：从容易 rejection 到极低可行率；
- core 结构：core 宽度、多个 MUS 数量、core 区域重叠程度；
- 投影比例：前文定义的直接采样变量数 $d$ 与求解器补全变量数 $e$ 的比例；
- 域：Bool、Enum、小整数、大整数范围；
- 求解难度：保持可行率相近但改变传播强度和搜索深度。

“约束稀疏度”不能只用约束条数表示；相同条数可能对应完全不同的变量交互图。应至少报告约束 arity 和 primal graph 密度。

### 真实场景

retail 案例可以作为贯穿示例，但不足以承担性能结论。至少需要多个业务域，例如权限审批、定价优惠、库存履约、排班／资源分配，并保留真实或拟真的非均匀业务分布。若没有真实生产数据，应明确称为 domain-inspired workloads，并公开生成参数。

### 指标

- 每个接受样本的求解器调用数；
- 包含 core 提炼调用在内的总调用数；
- 端到端时间、求解时间、分布计算时间、缓存查询时间；
- 接受样本吞吐量；
- 已覆盖不可行概率质量和边际质量增长；
- Certified MassCore 的上下界差、近似证书 $\alpha_B$，以及达到预设 $\alpha$ 所需的求解调用；
- 相同候选区域流下，在线选择相对当前可用最优缓存的累计差距，以及 Proposition 5／6 的界；
- 区域发现损失 $\mathcal A_T$ 与全部额外验证成本；对小字典分别验证 $2P+a_T$ 和有间隔时的 $2P+b_\rho$；
- cache hit、core 数量、平均宽度、包含关系和重叠；
- 小实例中，有限缓存贪心选择相对精确最优选择的覆盖比例；
- 小空间中，令 $N$ 为输出样本数、$\widehat\mu_N$ 为样本形成的经验分布，报告它相对精确目标 $\mu$ 的 total variation distance：
  $D_{\mathrm{TV}}(\widehat\mu_N,\mu)=\frac12\sum_{x\in F}|\widehat\mu_N(x)-\mu(x)|$；
- 大空间中预先选择边缘和联合事件的置信区间、校准误差；
- Item 分层配额误差及分层内部相对先验的距离；
- 反事实对的字段变化数、业务加权距离和目标命中率。

所有结果应使用多个随机种子和置信区间。小实例必须完整枚举目标分布，用于检查“完全不改变分布”的实现；大实例的统计检验只能提供证据，不能替代理论证明。

### 关键消融

- 无缓存／full no-good／raw core；
- core 大小排序与概率质量排序；
- Certified MassCore 与 greedy MassCore；
- 共享候选池与各自发现候选池；精确经验缓存选择与廉价贪心选择；
- 三变量分离问题族中的 $\theta$、缓存容量和有限运行长度；不可把命中率比当成时间加速比；
- 不同预算 $B$ 和剩余 horizon $H$；
- 使用总质量与使用边际质量；
- 删除式 core 与区间／points 扩张；
- 精确联合质量与 Monte Carlo 质量估计；
- 无限缓存与受限缓存；
- 受限缓存中的新增质量贪心、命中频率淘汰和最近最少使用策略；
- 只有 conditional sampling、加入 Item 分层、再加入成对生成。

## 可以主张和不能主张的内容

在完成证明和实验后，可以主张：

1. 一种面向投影业务输入的精确条件采样语义，求解 witness 不被误称为概率样本；
2. 一种以未覆盖先验概率质量和剩余采样预算为目标的 UNSAT 区域泛化问题；
3. 任意预算下保持安全并返回实例近似证书的 anytime 算法、有限缓存的 $1-1/e$ 覆盖保证，以及相对基线的求解调用收益分解；
4. 对 full no-good、raw core、MUS、minimum core、SampleSearch 和加权投影采样的系统比较；
5. Rule Item 上的分层校准，使测试覆盖目标和业务自然度可以同时表达；
6. 基于同一规则变换的精准拒绝和成对反事实测试。

不能直接主张：

- 首次把约束求解用于概率测试生成；
- 首次把 no-good 或 UNSAT core 用于采样；
- core 泛化在所有实例和所有批量大小下都更快；
- minimum core 必然不如 probability-mass core；当先验接近均匀或结构简单时二者可能相同；
- 任何输出 witness 都服从用户分布；
- 最小变化测试对具有因果意义。

## 建议的论文结构和实现顺序

第一阶段按 Online MassCore 的明确规格实现并验证最小闭环：

1. `solve::sample` 明确区分 sampled variables 和 existential witness；
2. 实现普通 rejection，建立精确语义和小域枚举验证；
3. 用完整赋值、raw assumption core 做两个缓存基线；
4. 以有限联合概率表实现精确区域质量，接入可恢复的端点查询状态机；
5. 实现平方根累计预算、质量优先／公平轮转和单调安全缓存；
6. 加入共享预算的 FIFO／绑定数量排序对照，并验证完整在线流程；
7. 对冻结缓存的单次任务输出质量上下界，在独立空缓存特例下以 weighted OUS 交叉验证；
8. 记录逐轮覆盖、业务与发现调用，验证收益分解、预算上界、收支平衡条件和证书有效性。

第二阶段扩展论文强度：

1. 将有限概率表扩展到大域上的结构化联合分布，优化并集质量计算，并单独评估其运行时间；
2. 实现 deletion MUS、minimum-cardinality 和小实例 exact maximum-mass oracle；
3. 为有限缓存实现新增质量贪心选择，并验证 $1-1/e$ 覆盖界；
4. 增加 `range`／`points` RegionGrow，并与 generalized no-good 对照；
5. 实现基于互斥 Rule Item 场景的校准；
6. 在 retail 之外加入多个业务域；
7. 最后加入成对反事实示例和用户可读诊断。

论文叙事应以第一项算法为技术主线，以 Rule Item 校准说明 Tapas 为什么不是一个通用 SAT 采样器的薄封装，再以成对反事实展示业务测试价值。
